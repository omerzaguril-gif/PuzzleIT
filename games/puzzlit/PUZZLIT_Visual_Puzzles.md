> **מה הקובץ הזה כן:** מאגר התוכן של משחק החידות הוויזואליות.
> **מה הוא לא:** מפרט האפליקציה. הוא לא מתאר את מחסן האותיות, הקלט הקולי, פאנל הבקרה או משחק השרשרת — אלה יושבים ב-`PUZZLIT_SPEC.md`.

## 1. מבנה חידה

```json
{
  "id": "p_002",
  "num": 2,
  "imageFile": "2.jpg",
  "level": 1,
  "answer": {
    "primary": "לשקר אין רגליים",
    "accepted": []
  },
  "hints": {
    "1": "פתגם על מעשי מרמה שנחשפים בסוף",
    "2": "3 מילים · דימוי גופני של יציבות"
  },
  "explanation": {
    "steps": [
      "הפתגם מבטא רעיון שאמת תמיד מתגלה בסופו של דבר",
      "מדובר במעשה מרמה שאין לו יציבות ולא יכול להמשיך לעמוד לאורך זמן"
    ],
    "finalPhrase": "לשקר אין רגליים"
  }
}
```

| שדה | משמעות |
|---|---|
| `id` | מזהה קבוע. לא מוחזר לשימוש ולא ממוספר מחדש לעולם |
| `num` | המספר שמוצג לשחקן |
| `imageFile` | שם הקובץ בתוך ה-ZIP |
| `level` | 1 עד 10. קובע את השלב |
| `answer.primary` | התשובה הקנונית. **מחסן האותיות נבנה ממנה** |
| `answer.accepted` | ניסוחים חלופיים שמתקבלים. משרתים בעיקר את הקלט הקולי |
| `hints` | שני רמזים, `"1"` ו-`"2"` |
| `explanation.steps` | שלבי ההסבר, נחשפים אחד-אחד אחרי פתירה |
| `explanation.finalPhrase` | התשובה כפי שהיא מוצגת בסוף |

## 2. שני כללים שאסור לשבור

### 2.1 תשובה היא אותיות עבריות ורווחים בלבד

אין ספרות ואין לטינית. מחסן האותיות לא מייצר אריחי ספרות, ולכן מספר בתשובה הופך את החידה לבלתי-פתירה.

מספרים נכתבים במילים:

| היה | תוקן ל |
|---|---|
| `10 המכות` | `עשרת המכות` |
| `תמונה אחת שווה 1000 מילים` | `תמונה אחת שווה אלף מילים` |

בנוסף הוסרו 13 וריאציות שהכילו ספרות (`4 אמהות`, `1 בפה 1 בלב`, `7 מדורי גיהנום` וכו׳) והוחלפו בצורת מילים.

שתי חידות שהיו באנגלית (`afternoon tea`, `ounces in a lifetime`) הוסרו מהמאגר מאותה סיבה.

### 2.2 רמז לא מכיל מילה מהתשובה

אף רמז לא מכיל מילה — או שורש של מילה — שמופיעה בתשובה שלו. רמז הוא אחד משניים:

- **קונספטואלי** — מה הביטוי אומר, מתי משתמשים בו, מה הוא מלמד
- **מבני** — מספר מילים, מקור (תנ"ך / תלמוד / סלנג / פתגם עממי), או דימוי כללי

שתי חידות דרשו פתרון מיוחד: `מילים כדורבנות` ו-`תמונה אחת שווה אלף מילים` מכילות את המילה "מילים", ולכן הפורמט הרגיל של רמז מבני (`"5 מילים · ..."`) דלף את התשובה. בהן הרמז סופר **חלקים** במקום מילים.

**האכיפה בשלוש שכבות:** קונסטריינט ב-SQL על עמודת התשובה, ולידציה ב-API של הפאנל שבודקת גם דליפת שורשים, ובדיקה בסקריפט ה-seed שנכשלת לפני שהיא נוגעת במסד.

## 5. התאמת תשובות

```
1. נרמול   — הסרת ניקוד, פיסוק וכל הרווחים; איחוד אותיות סופיות
2. השוואה  — מול primary ומול כל accepted
3. סובלנות — Levenshtein distance <= 2
```

`accepted` הוא רשימה מאושרת מראש. אין ניסיון להבין משמעות — וריאציה שלא ברשימה נדחית.

**נקודה שלא מובנת מאליה:** מחסן האותיות נבנה מהאותיות המדויקות של `primary`, ולכן הקשה על אריחים יכולה לייצר **רק** את הניסוח הקנוני. הווריאציות ב-`accepted` משרתות כמעט כולן את **הקלט הקולי**, שבו שחקן יכול לומר `להפוך את הקערה על פיה` במקום `הפכה את הקערה על פיה`.
