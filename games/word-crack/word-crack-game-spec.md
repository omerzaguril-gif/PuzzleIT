# פיצוח מילים (Word Crack) — Game Spec

קובץ: `word-crack-solo.html` — עמוד HTML עצמאי אחד (Vanilla JS, ללא ספריות חיצוניות מלבד גופנים מ-Google Fonts), RTL בעברית.

## הרעיון
משחק יחיד מול הזמן: מקבלים רמז אחד (מילה בודדת) לכל חידה, מנחשים מילה סודית. כל ניחוש שגוי חושף רמז נוסף. שתי דקות סה"כ, כמה שיותר מילים / נקודות.

## מסכים וזרימה
1. **תפריט ראשי** — קוביית "🧩 פיצוח מילים" (פותחת את המשחק) + כפתור קטן "🛠️ ניהול רמזים" (פותח מסך ניהול, ראה בהמשך).
2. **מסך הסבר** — בולט פוינטס קצרים על החוקים + כפתור גדול "הבנתי, בואו נשחק!".
3. **מסך משחק**:
   - שעון (2:00 יורד), מונה נקודות.
   - כפתור "✕ יציאה" — פותח modal אישור ("לצאת מהמשחק? ההתקדמות בסיבוב הנוכחי תאבד") עם "כן, צא" (חזרה לתפריט) / "לא, המשך" (ממשיך בדיוק מאותה נקודה — הטיימר מושהה בזמן ה-modal).
   - כרטיס עם: תווית "רמז X מתוך 5", רמזים שנחשפים אחד אחרי השני, שדה קלט + כפתור "נחש!" + כפתור "דלג ⏭", ורשימת הניחושים השגויים עד כה לאותה מילה.
   - ניחוש נכון: הזמן **נעצר**, מוצג "✓ <מילה>" בגדול/ירוק במשך 500ms, ואז עוברים למילה הבאה והזמן ממשיך.
4. **מסך סיום** (אחרי 2 דקות): ניקוד סופי + **דוח מפורט** לכל חידה באותו סיבוב — ✓/✗, ניקוד שהתקבל, כל הרמזים שנחשפו, כל הניחושים שנוסו, והתשובה הנכונה (אם לא נפתרה). כפתורים: "שחקו שוב" / "לתפריט הראשי".

## ניקוד
תלוי במספר הרמזים שנדרשו עד הפתרון: רמז 1→5 נק', 2→4, 3→3, 4→2, 5→1. דילוג = 0 נקודות, לא פוגע בציון.

## מאגר המילים
- **449 מילים**, כל אחת עם **5 רמזים** ורשימת **accepts** (וריאציות מקובלות — זכר/נקבה/יחיד/רבים/מילים מאותו שורש, למשל שוטר→משטרה/שוטרת/שוטרים).
- **סדר הרמזים: מהספציפי לכללי** — הרמז הראשון תמיד הכי ממוקד וחד-משמעי (למשל "חדק" לפני "חיה" עבור "פיל"), לא ההפך.
- **כל רמז הוא מילה בודדת אחת בלבד** (לא צירוף מילים).
- אף רמז לא כולל בתוכו את השורש/המילה של התשובה עצמה (למשל אסור "נגרייה" כרמז ל"נגר").
- קטגוריות: בעלי חיים, אוכל, כלי בית, טבע, מקצועות, ספורט/פעילויות, תחבורה, גוף, רגשות, בית ספר, חגים, כללי, גיאוגרפיה, ביגוד, משפחה, צבעים, זמן, כלי נגינה, טכנולוגיה, משחקים, אדריכלות/מבנים.
- קבלת ניחוש נכון: התאמה מדויקת, וריאציה ברשימת `accepts`, או צורת רבים בסיסית (היוריסטיקה גנרית ל-ים/ות).

## מסך ניהול רמזים (Admin)
- גישה מהתפריט הראשי → "ניהול רמזים" → שער אימייל (רק `omerzaguril@gmail.com` עובר).
- מסך מלא: חיפוש מילה, רשימה נגללת, כל מילה נפתחת לעריכה — 5 שדות טקסט לרמזים + חצי ↑↓ לשינוי סדר, כפתור "איפוס לברירת מחדל" לכל מילה.
- שינויים נשמרים ב-`localStorage` (מפתח `wordCrackOverrides_v1`), נטענים אוטומטית מעל מאגר ברירת המחדל (`WORDS_DEFAULT`) בכל טעינת עמוד. **ספציפי למכשיר/דפדפן** — לא מסתנכרן בין מכשירים.
- כפתור "ייצוא מאגר מעודכן" — מציג טקסט מלא של כל המאגר (כולל עריכות) בפורמט שאפשר להדביק בחזרה כדי לשלב לצמיתות בקוד המקור.

## מבנה טכני
- קובץ HTML יחיד, הכל inline (`<style>` + `<script>`).
- גופנים: Frank Ruhl Libre (כותרות/מילים) + Rubik (טקסט), נטענים מ-Google Fonts.
- פלטת צבעים: קרם (`--cream`), דיו (`--ink`), הדגשה כתומה-ארדמה (`--accent`), ירוק הצלחה (`--good`), אדום כישלון/יציאה (`--bad`).
- אין תלות בשרת — עובד לגמרי אופליין (חוץ מטעינת הגופן הראשונית).
